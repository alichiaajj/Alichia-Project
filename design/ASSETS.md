# Asal aset

- `reference.png`: papan UI Civic Pulse unggahan pengguna, disimpan sebagai acuan.
- `civic_logo.png`: potongan tanda logo pada bagian kiri atas papan UI pengguna, tidak didesain ulang.
- `supplied_logo.png`: logo.png asli unggahan pengguna, dipertahankan tanpa perubahan sebagai alternatif.
- `neighborhood.png`: ilustrasi lingkungan dari bagian splash pada papan UI pengguna.
- `community_hero.png`: ilustrasi baru dari imagegen bawaan; dipakai pada splash, onboarding, banner dan event.
- `event_garden.png`: potongan ilustrasi hero untuk workshop berkebun.
- Ikon: vector drawable lokal, tidak memerlukan font ikon atau koneksi jaringan.
- Poppins SemiBold dan Inter: Google Fonts, lisensi OFL masing-masing tersedia di folder ini.

## Prompt ilustrasi hero

Use case: illustration-story. Create one landscape illustration asset for the Civic Pulse Android app, based on the community illustration visual style in the supplied reference board (style reference only). Friendly Indonesian neighbors, men and women, tending a community garden and greeting each other, leafy neighborhood park, small houses and soft city skyline. Clean polished flat editorial illustration, gently shaded, teal #0F766E, mint #14B8A6, pale green #A7F3D0, gold #FBBF24, cream #F8FAFC. Wide 3:2 composition, people at center, trees framing sides. No words, no labels, no logo, no phone frame, no UI elements. This will be used as a hero illustration and event imagery inside a real Android app.
